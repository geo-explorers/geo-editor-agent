# SOURCES.md — evidence and attribution
## Practical use
### Build an evidence record
For each consequential statement, record the source URL, publication/observation date, relevant section and what it directly establishes. Label inference separately. A citation that proves someone made a claim does not necessarily prove the claim itself. Write the final description in original language and retain the evidence needed for review.
Read the source passage that supports the precise claim. A citation can indicate origin without corroborating truth. Distinguish publisher, document, author, claim and citation relationship.
Assess source authority for the particular question. Prefer primary material where available; corroborate unstable or contested facts. Record dates, relevant passages and uncertainty. Do not infer a person’s position from somebody else’s characterization without marking that inference.
Write original descriptions from verified facts. Check factual accuracy, source closeness and the description rules. Keep unsupported claims out of the final description and retain evidence for editorial review.
