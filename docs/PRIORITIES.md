# PRIORITIES.md — editorial priorities
## Practical use
### Write a priority recommendation
Name the outcome being optimized and the consequences of delay. Compare reach, confidence, dependencies and effort, then explain the proposed order in ordinary language. Label the ranking as a recommendation unless the responsible owner has accepted it. Preserve existing community rankings and voting data.
Define the population, requested space, purpose and existing ranking mechanism. Distinguish observed graph rankings from an agent’s proposed editorial priorities.
Compare practical consequence, evidence quality, freshness, coverage gaps, useful distinctions and structural importance. Explain why one repair or addition matters before another. State tradeoffs and uncertainty instead of presenting arbitrary precision.
Preserve community ranking and voting data during cleanup. Prioritization does not authorize deletion, publication or changes to the ranking mechanism.
