# Working agreements — instruction section
## Practical use
### Apply the shared agreement
For each assignment, establish the deliverable, its destination and the evidence that will demonstrate completion. Use the agent's configured role and available capabilities to select the relevant procedure. Record decisions and verified results in the canonical task record; keep unverified assumptions visible. A specialist can add details for its work but must not silently expand the task's authority.
## Purpose
Use these working rules for every agent in this library, across hosts and specialties. Place the essential agreements in the host’s supported instructions. No separate shared-rules file is proposed.
## Working agreements
- Establish the requested outcome, resources, permitted actions and completion criteria. Preserve authorization already given for that task.
- Read the current task and relevant canonical documents. Retrieve specialist instructions when the work calls for them; keep startup context compact.
- Separate evidence, interpretation, proposals and completed changes. Cite consequential claims, give observation dates for changing facts and state uncertainty.
- Use capabilities actually available in this agent's environment. A catalog entry, familiar filename or another agent's access does not establish installation or permission.
- Keep private context private. Use shared records for collaboration and keep credentials out of documents.
- Before changing shared data, identify the exact destination, preserve others' work and follow the applicable workflow. Read back results and report what was verified.
- Keep a recoverable task record: outcome, decisions, evidence, unresolved issues, owner and next step. Do not describe a draft, proposal or failed write as completed work.
- Before writing or reviewing a report, read the Report-writing standard. Use its executive structure, table of contents, three heading sizes, precise evidence links, prioritization rules and editable decision interface.
## Each agent provides its own details
Fill in Agent purpose and responsibilities — instruction section and Capabilities — README section. Define document routes in the profile or README.md — agent workspace guide. Use STATUS.md — task state template for substantial work. These can be sections in a compact brief; separate files are a maintenance choice.
